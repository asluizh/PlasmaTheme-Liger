# Liger

Aqua for KDE Plasma 6, after Mac OS X Snow Leopard → Mavericks, in the
"lickable" spirit: gel buttons, candy progress bars, traffic lights.

![Desktop](previews/desktop.png)
![Menu](previews/menu.png)
![Launcher](previews/launcher.png)

Parts (all generated by Python from `generator/`, nothing hand-drawn):

| Part | Where it goes |
|---|---|
| Plasma Style `Liger` (menu bar, 2D dock, popups, tooltips, widgets) | `~/.local/share/plasma/desktoptheme/Liger` |
| Window decoration (Aurorae) `Liger` | `~/.local/share/aurorae/themes/Liger` |
| Colour scheme `Liger` | `~/.local/share/color-schemes/Liger.colors` |
| Kvantum theme `Liger` (application widgets) | `~/.config/Kvantum/Liger` |
| Global theme `org.kde.liger.desktop` (ties it together + menu bar/dock layout) | `~/.local/share/plasma/look-and-feel/` |

## Install

```sh
./install.sh            # build and copy, nothing applied
./install.sh --apply    # also apply the global theme (keeps your panels)
./install.sh --layout   # apply AND replace panels with menu bar + dock
./install.sh --remove   # uninstall
```

Requires Python 3 with Pillow and NumPy to build; Kvantum for the application style.

## Develop

`python3 build.py` regenerates `build/`. `tools/testsession.sh` renders everything in
an isolated headless Plasma session and writes screenshots to `previews/`.
See **PROGRESS.md** for architecture, status and next steps.

## Notes

* After `./install.sh`, running sessions are refreshed automatically (KWin reconfigure,
  Plasma theme cache cleared). Restart applications to see Kvantum changes.
* Kvantum limitations: vertical (row) table headers reuse the horizontal header art
  rotated, and scrollbar arrows are always one per end.
* The window title cannot be engraved: Plasma 6's Aurorae has no text-shadow support.
